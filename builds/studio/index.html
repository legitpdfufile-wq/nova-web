Know the limits before you buy

Generated work needs review. Results depend on the request, models and computer. Broad native app creation, arbitrary game genres, Blender scenes and Roblox delivery are not finished promises of this offer.

Optional image creation needs a separately configured ComfyUI installation. AI model files are not included.

Will it fit your setup?

For the Studio desktop software

  • A Windows computer able to run your chosen local models.
  • Ollama with compatible local models installed for AI builds. Film Desk does not need it.
  • FFmpeg and FFprobe on PATH for local MP4 film export.
  • Node.js 20+ and Microsoft Edge for browser checks.
  • Python and Tcl/Tk are bundled in the maintained package. Run CHECK_SETUP.bat after extraction to check the local tools and compatible model setup.

For the free showcases

A modern browser is enough. No model download or paid AI account is required. The platformer needs a keyboard. Creator Desk records stay in the current browser profile; export a backup to keep a portable copy.

Studio’s local runtime does not require this chat or a continuing OpenAI subscription. Installing and running the separate local models is your setup responsibility.

A few useful answers

Is Studio a hosted website service?

No. It is downloadable local Windows software. The showcases are hosted examples you can use in a browser.

Do I need a paid OpenAI account to run it?

No continuing OpenAI payment is required for the local runtime. Local model software, downloads and compatible hardware are still required.

Does buying Studio include the AI models?

No. Install compatible models through Ollama separately. Image generation is optional and requires a separate ComfyUI setup.

Does it build absolutely any app or Roblox game?

That is not a supported promise of this launch. The showcases demonstrate specific workflows. Broader specialist delivery remains under development.
